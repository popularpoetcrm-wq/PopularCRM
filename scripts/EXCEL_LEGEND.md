# Легенда Excel → CRM

Источник: `Таблицы_реальные/Популярный поэт.xlsx`, `Идея.xlsx`

## Структура листа группы

| Колонка | Смысл |
|---------|--------|
| A | Имя |
| B | Размер футболки (`R` в шапке) **или** цена, если размера нет |
| C | Цена пакета (PLN за цикл, обычно 4 занятия), напр. **395** |
| D | День рождения |
| E… | Даты занятий в шапке. **Первая дата = старт группы / первый столбец журнала** |

## Блоки людей

1. **Верхний блок** (до пустой строки) → в группе **ходят** (`enrollment.status = active`)
2. **После пустой строки** → **не ходят** (`ended`)
3. Блок «Майки» + числа (50 и т.п.) → склад футболок, **не ученики**

## Метки в ячейках дат

| Метка | Смысл |
|-------|--------|
| `проба` / `Проба` | Пробное занятие |
| `1` / `2` / … | Номер занятия в текущем пакете (был на занятии) |
| `1$` / `$1` | Первое занятие нового абонемента: человек купил и оплатил весь пакет |
| `5$` / `9$` / `13$`… | То же самое: новый пакет; число — сквозной счётчик занятий |
| `$-` | Новый пакет оплачен, но обычное занятие в этот день не списываем |
| `$*+` | Новый пакет оплачен, в этот день была отработка; обычное занятие пакета не списываем |
| `-` | Не был (предупредил) |
| `*+` | Отработка |
| пусто | Не отмечали / не ходил в этот день |

Пакет = обычно **4 занятия**, цена из колонки `$` у человека. Любая отметка
`$` в датированной ячейке запускает новый цикл и подтверждает оплату всего
пакета. Все такие отметки с датой до **30.07.2026 включительно** считаются
оплаченными. Один `$` создаёт одну оплату пакета, а не оплату одного занятия.

Для остатка последнего пакета считаем только обычные посещения от последней
`$`-отметки. `-` и `*+` обычный кредит пакета не списывают.
