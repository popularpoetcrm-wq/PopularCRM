# Легенда Excel → CRM

Источник: `Таблицы_реальные/Популярный поэт.xlsx`, `Идея.xlsx`

## Структура листа группы

| Колонка | Смысл |
|---------|--------|
| A | Имя |
| B | Размер футболки (`R` в шапке) **или** цена, если размера нет |
| C | Цена пакета (PLN за цикл, обычно 4 занятия), напр. **395** |
| D | День рождения |
| E… | Даты занятий в шапке. **Первая дата = старт группы / первый столбец журнала** |

## Блоки людей

1. **Верхний блок** (до пустой строки) → в группе **ходят** (`enrollment.status = active`)
2. **После пустой строки** → **не ходят** (`ended`)
3. Блок «Майки» + числа (50 и т.п.) → склад футболок, **не ученики**

## Метки в ячейках дат

| Метка | Смысл |
|-------|--------|
| `проба` / `Проба` | Пробное занятие |
| `1` / `2` / … | Номер занятия в текущем пакете (был на занятии) |
| `1$` / `$1` | Первое занятие нового абонемента: создать начисление за цикл; это **не подтверждение оплаты** |
| `-` | Не был (предупредил) |
| `*+` | Отработка |
| пусто | Не отмечали / не ходил в этот день |

Пакет = обычно **4 занятия**, цена из колонки `$` у человека. `1$` запускает
цикл `1/4 → 2/4 → 3/4 → 4/4`: CRM выставляет сумму и ждёт отдельного
подтверждения денег из P24/банка или от администратора.
